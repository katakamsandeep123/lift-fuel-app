LIFT & FUEL — Android setup

Files:
- index.html: app interface and tracker
- manifest.json: installable web app metadata
- sw.js: basic offline cache

Important:
This is a mobile-friendly Progressive Web App (PWA), not a native APK. For installation as an app, the files must be hosted on an HTTPS website (for example, GitHub Pages). Then open the HTTPS address in Chrome on your Redmi Note 14 Pro+ and choose the browser menu > Add to Home screen / Install app.

Reminder reliability:
- In-app notifications work while the app page is open and the browser allows notifications.
- A web page cannot reliably schedule notifications after it is fully closed without a push server or native Android alarm support.
- For reliable reminders, open the app > Diet & reminders > Export reminders to calendar (.ics). Import the downloaded file into Google Calendar, and ensure event notifications are enabled. Check imported event times and repeat rules after import.

How to use:
1. Open Today to see the workout and tick off meals.
2. Open Workout to choose the day and tick exercises.
3. Quick add nutrition lets you record food, protein grams and calories.
4. Open Progress to save weigh-ins.
5. Your entries are saved in local storage on this device/browser. Clearing browser storage may erase them.

Personalized defaults:
- Body weight: 60 kg; goal: 75 kg
- Protein target: 115 g/day
- Calories starting target: 2,600 kcal/day
- Vegetarian meal suggestions Monday and Saturday
- Suggested gym time: 6:00 AM
- Workout schedule: Mon chest/triceps, Tue back/biceps, Wed legs/abs, Thu shoulders, Fri chest/back, Sat arms/abs, Sun rest.

Nutrition values are estimates; adjust quantities and targets to your own needs. Avoid painful exercises and progress gradually.
